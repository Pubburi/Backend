- 사용자 승인 범위: 로컬 OpenSearch 상품 검색을 F02/R06/R02에 연결하는 계획, 권리/출처를 확인한 주류 데이터와 추천 학습 순서 정리.
- 세 하위 에이전트는 국내 원천·공개 학습 데이터·검색 계약을 읽기 전용 조사했다. 조정자가 Backend 문서·Notion·기존 예약만 수정한다.

- 실제 수집·API 신청·외부 문의·엔진 설치·학습은 이번 작업이 아니다. 기존 시드/이미지 권리 감사와 최소 행동 데이터 정책도 후속 작업이다.
- 문서 링크/작업 ID·기존 범위와 충돌·비밀정보/생성물·공백 검사를 수행하고 PR의 필수 CI·최신 Codex 리뷰 후 병합한다. 병합 근거는 기획과 ignored 체크포인트에 남긴다.

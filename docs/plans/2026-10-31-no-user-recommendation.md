# 실사용자 없는 추천 모델 개발 기준

- 사용자 확정: 비상업 사이드 프로젝트이며 외부 사용자가 없어 행동 데이터가 쌓이지 않는다. 데이터/모델 개발은 근거 있는 에이전트 판단으로 진행한다.
- 세 조사 에이전트가 모델·평가·기존 계획 충돌을 읽기 전용 검토했다. 조정자가 공통 계획·Notion·기존 예약을 수정한다.
- DAT03을 명시 취향·시연/맥락 입력·고정 평가 명세로, DAT04/AI03을 카탈로그 실제 fit·기준선 비교·시나리오/상품군 분리·재현 보고서로 변경한다.
- B0 기본순과 B1 특성/TF-IDF 유사도를 비교하고, 데이터 적합성에 따라 비지도 표현 학습 후보를 실험해 채택/미채택 근거를 남긴다. 실사용자·로그·평가자 모집을 기다리지 않는다.
- 모든 20개 필수 기능·기한·소유권·PR/리뷰/CI·로컬 개발·데이터 권리·허위 성과 금지 원칙은 유지한다. README는 더 강한 실제 구현 사례가 없는 이번 계획 변경에서 유지한다.
- 정적 확인: 충돌 문구·작업 ID·상대 링크·저장소 비밀정보/생성물·공백 검사. 모델 실행이나 데이터 수집을 완료했다고 표시하지 않는다. 실제 PR/CI/병합 근거는 Notion과 ignored 체크포인트에 기록한다.
